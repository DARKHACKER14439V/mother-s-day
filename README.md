# 💖 Happy Mother's Day Website 🌸

A beautiful, emotional, and fully responsive Mother's Day surprise website created with HTML, CSS, and JavaScript to express love and gratitude to my mother.

## ✨ Features

* 💖 Premium animated design with pink and purple gradients
* 🌸 Floating hearts, flowers, and glowing particles
* 📱 Fully mobile-friendly and responsive
* 🖼️ Circular Ghibli-style memory illustrations
* 🎵 Background music surprise
* 💌 Emotional letter to my mother
* 🖼️ Memory gallery with four special moments:

  * Memory 1 – Sweet Moment
  * Memory 2 – Warm Smile
  * Memory 3 – Little Joy
  * Memory 4 – Forever Love
* 🏆 "Best Mom in the World" award section
* ⏳ Live counter showing how long my mother has been caring for me (since 10 March 2009)
* 🎁 Interactive surprise button with animations and confetti

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (Vanilla)

## ❤️ Special Message

This website is a heartfelt digital gift dedicated to my mother, thanking her for her endless love, sacrifices, and support. Every achievement in my life is because of her.
